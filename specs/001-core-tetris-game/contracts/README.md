# API 合約定義

**目的**: 定義所有模組的公開介面（Public API），確保模組間的契約清晰明確。

---

## 合約文件列表

| 文件 | 說明 |
|------|------|
| `game-contract.md` | 遊戲主控制器（Game）的公開 API |
| `systems-contract.md` | 遊戲系統（碰撞檢測、消行、計分等）的 API |
| `rendering-contract.md` | 渲染系統（Renderer, GridRenderer 等）的 API |
| `input-contract.md` | 輸入處理系統（InputHandler）的 API |
| `logging-contract.md` | 結構化日誌系統（Logger）的 API |

---

## 合約原則

1. **清晰性**：每個方法的輸入輸出必須明確定義
2. **不可變性**：輸入參數應避免被修改（除非明確說明）
3. **錯誤處理**：明確定義異常情況的處理方式
4. **意圖表達**：方法名稱必須清楚表達意圖（符合憲法原則 6）
5. **測試性**：所有公開 API 必須可測試

---

## 合約格式

每個方法應包含：
- **簽名**：函數名稱、參數、回傳值
- **用途**：簡短描述
- **前置條件**：呼叫前必須滿足的條件
- **後置條件**：呼叫後保證的結果
- **副作用**：是否修改狀態
- **範例**：使用範例
